🐦 Flappy Bird Mini Game (JavaScript)

A simple Flappy Bird clone built using HTML, CSS, and Vanilla JavaScript.
This mini game runs directly in the browser using the HTML5 Canvas API.


🚀 Features

     🐤 Smooth bird movement with gravity
    
     ⬆ Jump using Space, Arrow Up, or X
    
     🌉 Randomly generated pipes
    
     💯 Real-time score counter
    
     ❌ Collision detection
    
     🔄 Game restart after Game Over
    
     🎨 Background and sprite images

🛠️ Technologies Used

    HTML5 – Canvas setup
    
    CSS3 – Styling & background
    
    JavaScript (Vanilla JS) – Game logic
    
    Canvas API – Rendering graphics
